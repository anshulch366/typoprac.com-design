TYPOPRAC FRONT-END STARTER
==========================

FILES
- index.html              Main responsive typing practice page
- css/styles.css          All styles and responsive breakpoints
- js/app.js               Typing interaction, timer, WPM/accuracy, keyboard highlight, local streak
- privacy.html            Privacy policy starter
- terms.html              Terms and conditions starter
- cookies.html            Cookie policy and tracking assessment
- refund.html             Refund policy starter

RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or serve the folder with any static web server.
4. No npm install, build step, API key, database, external font or image asset is required.

IMPORTANT BEFORE PUBLIC LAUNCH
- Replace [LEGAL BUSINESS NAME], [BUSINESS ADDRESS], [SUPPORT EMAIL], [PRIVACY CONTACT EMAIL] and jurisdiction placeholders.
- Verify the legal operator and support contact. Do not publish invented business details.
- Confirm your hosting provider's server logs, backups, retention, processors and cross-border handling.
- This starter build intentionally has no analytics, ad pixels, external embeds, account registration or payment processing.
- If you add analytics/marketing cookies or third-party embeds, reassess notice and consent, update the Cookie and Privacy Policies, and ensure optional trackers do not load before required consent.
- If you add accounts, forms, payments or leaderboard submissions, implement server-side validation, security, retention/deletion workflows, grievance handling and appropriate privacy notices.
- The leaderboard contains clearly marked illustrative demo rows, not real users or testimonials.
- No third-party images or avatar photos are used. All visual marks are CSS/text symbols; there are no image copyright or alt-text assets to license.
- Have an Indian privacy/consumer-law professional review the policies and your actual data flows. This is a code starter, not a legal compliance certification.

ACCESSIBILITY NOTES
- Semantic landmarks, skip link, visible focus, labels, keyboard-operable buttons, status announcements and reduced-motion handling are included.
- Test with keyboard only, screen readers, zoom, small screens and a contrast checker before release. Automated checks cannot certify WCAG conformance.
- The practice text area is transparent over the prompt so users can type directly; ensure keyboard and screen-reader testing on target browsers.

DATA NOTES
- WPM and accuracy are calculated locally in the browser.
- A localStorage date marker supports the sample streak display.
- The code does not send typed content or local practice state to a server.
