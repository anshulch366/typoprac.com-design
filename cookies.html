Cookie Policy

Last updated: 13 November 2026

Current build assessment: This starter website does not set advertising or analytics cookies and does not load third-party tracking scripts. It uses browser localStorage for a limited practice-streak marker. A cookie-consent banner is not included because there are no optional tracking cookies to consent to in this build. Reassess this before adding tools or embeds.

1. Cookies and similar technologies

Cookies are small data files stored by a browser. Similar technologies include localStorage, sessionStorage, pixels and SDKs. This page explains the current starter build and must be updated if the implementation changes.

2. What this site currently uses

  • Local storage: stores the date of a practice session on this device to display a streak marker. It is not sent to TypoPrac by the supplied JavaScript.
  • Cookies: no cookies are intentionally set by the supplied front-end code.
  • Analytics / advertising: none are included.
  • Third-party embeds: none are included. The design uses system fonts and locally hosted assets only.

3. Do you need a consent banner?

For this exact implementation, an optional analytics/advertising cookie banner is not required by the code because those technologies are absent. If you add analytics, advertising, session replay, social embeds or other tools that process personal data or access device storage, first assess the applicable Indian legal requirements, disclose the purpose and provider, and obtain valid consent where required before activating non-essential tracking. Provide a real reject/withdraw option and do not make optional tracking a condition of basic practice access.

4. Managing local storage

You can clear TypoPrac site data using your browser’s privacy/site-settings controls. Clearing it may remove the locally stored practice marker. Browser controls differ by device and browser.

5. Changes

We will update this policy if cookies, analytics, advertising, third-party embeds or other storage technologies are introduced. Contact [PRIVACY CONTACT EMAIL] with questions.
